# 苏打阅读 · 项目说明

苏打阅读是面向中文读者的英语沉浸阅读工具。它把许可原文做成可点读、可听读、可划线、可回原文复习的编辑式阅读器，而不是带打卡、经验值和功能卡片的学习 App。

当前就是 **Vite + React 网页**，配可选的本地 FastAPI 翻译与内容接口。无需登录；阅读进度、生词、划线、章节位置和偏好存在浏览器里，并可手动导出完整备份。

## 它解决什么问题

英语阅读里最常见的打断是：查词跳出正文、词义是词典义而不是这句话里的意思、听读对不上当前句、生词本和原文脱节。苏打阅读把这些动作留在纸面上：

- 点词或短拖短语，中文语境义出现在该词正下方（行间注，不遮下一行）。
- 点句末标点，中文整句译文插在该句下面；再点一次收起。
- 全文朗读按句跟读，可暂停、再读本句、从此句朗读、划出本句。特别长的一句会拆成几小段读完，进度仍按整句计算。
- 生词本的「原文」回到当初那一句，并展开译义。

不做的事同样明确：没有连续打卡、XP、徽章、气泡装饰，也没有在阅读页讲解采集流水线或版权政策。

## 给谁用

- **读者**：按 CEFR（A1–C2）读当日文章、书架馆藏和自己导入的书，查词、听读、划线、复习生词。无需注册或登录。
- **管理员**：本机 `/admin` 仍可配置内容来源和翻译模型路由；阅读端不显示管理入口。

产品气质是编辑部出品的读本，不是课程平台。视觉以 `reference-reader.png` 为阅读页基准：日间暖象牙纸 + 炭黑字 + 薄荷点缀；夜间深墨蓝 + 暖灰字 + 克制青色。

## 读者能看到的界面

| 入口 | 做什么 |
| --- | --- |
| **今日** | 按当前 CEFR 换一篇有正文的主打文章，并给出中文导读。没有该级别活文时，注入馆藏里同级别的完整文章；进行中的文章可「继续阅读」，到期生词可直接复习。 |
| **阅读器** | 点词行间义、点句译、划线、跨章查找、逐章听读、纸色与版式；桌面目录和手机目录共享阅读位置。 |
| **书架** | 编辑目录 + 本地导入（EPUB / TXT / 文本型 PDF）。EPUB/TXT 有章节目录，PDF 使用页码导航。 |
| **生词** | 学习中 / 已掌握视图、全部到期统计与分批 FSRS。两阶段回忆、忘记重排、完整撤销、恢复复习和正确章节的「原文」。 |
| **我的** | 水平测试、主题、纸面与节奏设置，以及备份、恢复、删书和分类清空。 |
| **管理站** `/admin` | 本机手动采集、自动验证和模型路由，没有账号管理或闲置人工复核队列。 |

导入文件只留在浏览器里。TXT 支持 UTF-8 和常见 UTF-16，并识别独立成行的常见章节标题。EPUB 按 spine、导航/NCX 标题、段落和表格还原正文；PDF 按行距分段并提供页码导航。扫描件不做文字识别。

## 学习与数据闭环

- 首次设置可选 18 道本地原创题，覆盖 A1–C2 的词义、句意和短文理解；评分对低级别基础错误采用保守估计，只用于选择起步材料。
- 普通点词只展开译义，不自动收藏；开启「生词标记」后，单词或短语在取得译义后自动入库。相同文章、词和原句不会重复建卡，重新标记已掌握词会恢复原记录。
- 首屏只显示词和原句，先选「认识 / 不认识」再揭示答案；认识后需用「记错 / 困难 / 正确 / 轻松」确认，不认识以 Again 在本批重排。空格、1–4 和 Ctrl+Z 均可操作。
- 每批沿用 10–50 张设置，显示全部到期数与本批数量，可继续下一批；每张卡独立 FSRS。掌握与撤销写回完整词项，已掌握页可恢复复习并立即到期。
- 最后一章末尾可复习本文生词，并记录「太简单 / 刚好 / 太难」；等级调整建议需用户确认，不自动改水平。
- 「数据管理」导出 `schemaVersion: 2` 的 JSON，包含设置、全部学习 bucket 和导入书；当前仅接受版本 2，不保留无正式用户阶段的旧版迁移分支。恢复前先校验与预览，写入异常时回滚。密钥、会话和内容数据库不进入备份。

## 阅读器怎么用

### 查词与整句

- 点一个词，或拖一小段短语：英文留在原位，中文语境义用 CSS ruby 衬在词下，占行高，不盖住下一行英文。
- 词典常见义和语境义明显不同时，再给一行更安静的「常见」。
- 代词、指示词（`it` / `those` / `these` 等）只显示文中指代，标「文中指代」，不再给词典常见义。
- 桌面学习栏是补充，不是弹层：标「语境义」或「文中指代」，必要时才标「常见义」。
- 点句号、问号等句末标记插入整句中文；再点收起。不要用这个标记改去跳朗读。
- 已保存的生词在后文里保持浅薄荷下划线。

### 听读

浏览器 Web Speech API，一次以一句为单位跟读（Chrome 的 `pause()` 不可靠，暂停等于停掉当前句并记住光标）。超过约 120 字的长句会在词边界拆开朗读，避免引擎中途停住；「再读本句」会把这些小段读完再停。朗读进行中每 10 秒会在未暂停时轻推一次引擎。

- 朗读全文 / 暂停 / 继续（停在本句，条不收）
- 上一句、下一句；「从此句朗读」
- **再读本句**：只把当前句读完，然后停住（条仍在）
- **划出本句**：把正在听的整句做成一条连续划线；Shift+M 同样有效
- 慢 / 常 / 快；速度记进阅读偏好
- 空格播放/暂停，即使焦点在朗读条按钮上
- 打开「查找」或「阅读设置」会暂停朗读，条保留
- 剩余分钟按剩余词数和听读位置算，听读条开着时跟听读进度走

### 其它编辑工具

- 持久划线（连续词合并成一条底色，而不是每个词一个色块）
- 文内查找，单词或连续词组都算一处，显示第几处 / 共几处，无结果时标明
- 复制原句：先走同步 `execCommand`，避免手势丢失；失败显示「未复制」
- 本地翻译记忆：合并进行中的同一请求，命中则不再请求翻译接口

## 翻译与内容

词译默认路由是 **DeepSeek**，但它可能计费。DeepSeek、cheapApi 和自定义线路默认都被零预算护栏阻断；只有显式启用付费、设置正数预算并满足请求模式后才可能调用。管理员可在模型路由里加 OpenAI 兼容端点；密钥放在 `backend/data/provider_overrides.json`，不要写进前端环境变量。详见 `docs/translation-provider-setup.md`。

查找顺序大致是：同一句里已收藏的释义 → 浏览器翻译记忆 → 进行中的同一请求 → 本机翻译接口。换一句不会沿用上一句的收藏义。缓存键包含词、所在句和内容哈希。离线词典义只供这一次显示，不写入会挡住后来语境翻译的长期缓存。

生词按「文章 + 词 + 原句」区分，存在本机浏览器里。

内容侧：

- **采集** = 抓取许可原文（官方 API、RSS、获准来源），不是随便爬站。
- **验证** = 自动检查许可、语言、篇幅、新鲜度，不是人工审稿队列。
- 通过的文章生中文导读后进今日源。
- 中文维基精选摘录可以译成受 CEFR 控制的准确英文，当作阅读正文。
- 首页每篇文章有中文介绍。正文下不放来源免责脚注。

## 技术结构

```text
读者网页（src/）
  ├─ 今日 / 书架 / 生词 / 我的
  ├─ screens/ReaderScreen.jsx   章节阅读器与听读
  ├─ screens/PlacementScreen.jsx 本地水平测试
  ├─ screens/ReviewSession.jsx  复习会话
  ├─ lib/backup.js              版本 2 备份校验、导出与失败回滚
  ├─ lib/vocabulary.js          生词幂等写入与掌握恢复
  ├─ lib/study.js               查找、原文定位与学习工具
  └─ lib/api.js                 翻译记忆、请求合并与可选 Feed

packages/core                   章节模型、分词、句切分、朗读进度、FSRS

本地 API（backend/）
  ├─ FastAPI 翻译网关           DeepSeek 等，进程内缓存
  └─ 内容服务                   采集、校验、导读、免登录 Feed，SQLite
```

后端没开时，内置文章、本地书籍、水平测试、复习和备份仍可使用；在线今日源与云端词译才需要 FastAPI。个人数据始终使用浏览器本地存储。

## 本地运行

在仓库根目录安装依赖并启动网页：

```powershell
npm ci
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

需要在线今日源、云端词译或采集时另开 FastAPI（默认 `http://127.0.0.1:8000`）。阅读端不需要口令；模型配置只放在后端，前端 `VITE_API_BASE` 指向该地址。DeepSeek 的付费启用条件见 `docs/translation-provider-setup.md`。

```powershell
cd backend
$env:PYTHONPATH="."
..\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

模型密钥只放在 `backend/.env` 或管理端本机覆盖文件，不要写进前端环境变量或源码。

## 产品硬规则（摘要）

完整条文在 `AGENTS.md`。开发时优先记住：

1. 词义在字下，不在弹层、卡片、抽屉里。
2. 句末点是整句翻译开关，不是朗读跳转。
3. 阅读页不讲管道、许可、隐私课。
4. 首页 CEFR 是活控件，必须换有正文的文章。
5. 没有 streak / XP / 游戏化。

## 当前阅读体验里已经落地的优化

这些是原型阶段从读者路径补上的能力，不是路线图：

- 阅读器从 `App.jsx` 拆到独立屏幕，听读改为逐句 + 世代令牌，避免取消上一句时误停下一句。
- 暂停保留朗读条；再读本句、划出本句、空格在条上仍可用。
- 查找/设置打开时暂停听读，且不再因为查找栏重绑快捷键而把朗读状态拆掉。
- 整句划线是一条连续底色；生词「原文」能回到原句并展开译义。
- 翻译请求合并、本地记忆、复制走同步剪贴板手势。
- 文内查找可命中连续词组；导入的 EPUB 按段落、表格单元格和章节地址还原正文，文本型 PDF 按行距分段。
- 首页等级切换立刻换文；较慢的上一次推荐不会把水平和文章盖回去。补进馆藏的文章在再次排序后仍标为备用导读。
- 从生词回到原句后，不会被旧的滚动位置拉走。点在已打开词语的行间区域不会收起注释。
