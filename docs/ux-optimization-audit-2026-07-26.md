# 苏打阅读体验与生产化优化审计（历史记录）

> 审计日期：2026-07-26。本文记录当时版本和当时的本地检查，不是当前发布验证或当前架构说明。当时截图位于未纳入仓库的本地输出目录，因此本文不再链接这些不可公开访问的文件。当前本地-only 范围、测试和付费护栏以 README、现行代码及最新 CI 结果为准。

## 当时的结论

- 阅读器保持正文优先，桌面三栏和手机单栏均可用；日间暖白与夜间深色主题经过当时视觉复核。
- 点词翻译使用前端和后端内存缓存，相同并发请求合并，并按线路质量、近期成功率和延迟动态排序。
- 逐句翻译由句末标点直接触发，句末触控区不生成额外圆点，也不独占一行。
- 内容候选执行英文与证据完整性检查。当时本地候选池的统计为：500 条可见候选中，186 条合格、304 条拒绝；这些数字不是当前数据库状态。
- 当时已具备付费模型默认关闭、每日预算为 0、生产模式关闭演示短信和管理接口 Token 校验。当前版本还把所有 `may_charge=True` 的廉价与自定义线路纳入同一护栏。

当时的审计不建议直接开放公开注册。真实短信、持久化账号、生产数据库、隐私与注销流程、备案材料和连续内容影子审核不在当前本地-only 版本中。

## 当时检查的视觉与交互状态

- 桌面首页：上海时区动态日期、CEFR、预计时长和明确的开始阅读操作。
- 上下文点词：`miniature` 在当时实测中得到“微缩版”，译义显示在单词下方，右侧学习面板显示补充信息。
- 手机阅读器与句译：检查正文行宽、段距和工具密度；句末标点展开与收起译文。
- 夜间模式：检查深蓝黑背景、低眩光正文色和与日间一致的操作位置。

上述是当时的人工观察记录，不代表本轮重新生成了截图或重复了这些设备检查。

## 当时的翻译实现与实测

当时已实现的机制：

1. 浏览器会话缓存和后端 TTL LRU。
2. Single-flight 合并相同并发请求。
3. 失败短缓存，避免高负载时反复冲击同一线路。
4. 动态路由以及 429、超时和 5xx 的短时熔断。
5. 付费开关、每日预算、单次上限和请求模式护栏。

当时的小样本实测记录：

| 场景 | 历史结果 |
|---|---:|
| 免费模型首次上下文翻译 | 约 1.37–1.66 秒 |
| 同一会话内存命中 | 约 101 毫秒端到端 |
| 当时可用免费首选 | ModelScope，5/5 成功，平均约 1.49 秒 |
| 当时付费调用 | 0；`PAID_PROVIDER_ENABLED=false` |

这些数字不是性能基准，也不是当前供应商可用性声明。当时尚未完成大样本人工准确率评估或 P50/P95 压测。

## 当时的内容质量检查

- 标题与摘要分别执行英文检查。
- 证据摘要设置最小长度，未获全文许可的来源只保存元数据和链接。
- 首页区分备用内容与当天发布内容。
- 当时建议继续影子采集、抽检来源日期/版权/事实/CEFR，并对健康、因果和预印本内容保持人工审核。

## 当时的剩余风险

- 尚未完成完整 WCAG 审计、色彩对比自动扫描和读屏任务测试。
- 浏览器登录状态偏演示性质，不能当作生产账号系统。
- 弱网、离线恢复和长篇 EPUB/PDF 的内存压力仍需更多设备验证。
- 免费模型策略与可用性会变化，不能把“当前免费”理解为无限并发或 SLA。
